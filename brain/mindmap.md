# Feature mindmap

## Feature mindmap

```mermaid
mindmap
  root((ownerrez-higgsfield-video))
    Setup
      Readiness check, READY or NOT READY
      Higgsfield CLI and browser sign-in
      ffmpeg and ffprobe
      Optional OwnerRez API via .env
    Gallery
      OwnerRez API
      Public listing page
      Local folder
      Full-resolution originals only
      800px previews
    Planning
      One strongest frame per space
      6 to 9 beats, highlight reel
      Camera move per beat
      Named negatives per beat
      16:9 or 9:16
    Generation
      Estimate first
      Test clip first
      Hard budget ceiling
      Staggered submissions
      Failed beat recorded, run continues
    Review
      2x2 compare grid
      Approve or reject per clip
      Rejected clips kept aside with reason
      Re-roll or drop
    Stitch
      Normalise each clip
      0.5s crossfades
      H.264, silent, faststart
      ffprobe verification
      Poster frame
    Safeguards
      Never invent features
      Never spend without an approved number
      Never handle credentials in chat
```
